# lucky-catch-tracker
Adesktop app in early development, for players of the game Aniimo.

• Reads the screen to detect and count catches automatically, replacing manual logging
• Tracks each player's progress toward Lucky and Super Lucky Catch pity, with a counter that resets on each Lucky Catch
• Each player runs their own copy, since pity is specific to the playerers of the game Aniimo.
